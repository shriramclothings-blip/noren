## ✅ PRINT DIALOG CHECKLIST

Before clicking "Print", verify EVERY item:

```
☐ SCALE: 100%  (NOT "Fit to page")
☐ PRINTER: [Your thermal printer name]
☐ MARGINS: 0mm (all sides)
☐ PAPER SIZE: 50mm × 25mm
☐ HEADERS/FOOTERS: DISABLED (unchecked)
☐ BACKGROUND GRAPHICS: ENABLED (checked)
☐ ORIENTATION: Landscape
```

**If even ONE is wrong, labels will print incorrectly!**

---

## ⚠️ COMMON MISTAKES

```
❌ Mistake 1: Using "Fit to page"
   → Result: Labels print too small!
   → Fix: Use 100% scale ALWAYS

❌ Mistake 2: Setting margins
   → Result: White borders on labels!
   → Fix: Set margins to 0

❌ Mistake 3: Disabling "Background graphics"
   → Result: Barcode won't scan!
   → Fix: Enable background graphics

❌ Mistake 4: Forgetting "Headers/Footers"
   → Result: Content gets cut off!
   → Fix: Disable headers and footers

❌ Mistake 5: Wrong printer selected
   → Result: Prints to wrong printer!
   → Fix: Select thermal printer model
```

## 🔧 TROUBLESHOOTING QUICK FIX

| Problem | Fix |
|---------|-----|
| **Labels too small** | Check Scale = 100% in print dialog |
| **Labels have white borders** | Set Margins = 0 |
| **Barcode won't scan** | Enable "Background graphics" |
| **Text cut off** | Disable "Headers and Footers" |
| **Wrong printer** | Select thermal printer from list |
| **Printer not found** | Reinstall printer driver, restart Windows |
| **Paper jams** | Check label roll installation |
| **Poor print quality** | Set print quality to "Best", clean printer head |

## 🎯 STEP-BY-STEP PRINT PROCESS

### Step 1: Generate Labels
```
1. Open POS App
2. Inventory → Select Products
3. Print Labels button → Select quantity
4. Click "Download PDF"
5. PDF opens in browser (or saves)
```

### Step 2: Print Dialog Setup
```
1. In browser: Press Ctrl+P
   (or File → Print)
2. Print Dialog opens
3. Printer: Select thermal printer
4. Scale: Change to 100%
5. More Settings:
   ├─ Margins: Change to None/0
   ├─ Paper: 50mm × 25mm
   ├─ Background: Check (enable)
   └─ Headers: Uncheck (disable)
6. Review: All correct?
```

### Step 3: Print
```
1. Click "Print" button
2. Printer starts printing
3. Labels come out one-by-one
4. Done! ✓
```

## 🆘 EMERGENCY QUICK RESET

If printing is completely broken:

```
1. Close browser/app
2. Restart Windows
3. Unplug thermal printer (wait 10 sec)
4. Plug thermal printer back in
5. Wait 30 seconds (let Windows detect)
6. Open app
7. Try printing again
```

**This fixes 90% of printer issues!**

## 📞 SUPPORT

### Printer Won't Print?
1. Check Windows Printer Settings
2. Reinstall printer driver
3. Restart Windows
4. Contact printer manufacturer

### Labels Wrong Size?
1. Verify print scale = 100%
2. Check Windows printer properties (50×25mm)
3. Run test print
4. Contact support if issue persists

### Barcode Not Scanning?
1. Enable background graphics in print dialog
2. Try different barcode scanner
3. Clean printer head
4. Increase barcode height in settings
