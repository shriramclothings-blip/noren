# 🏷️ Quick Reference: Professional Barcode Label Printer

## ⚡ 30-SECOND QUICK START

1. **Open Barcode Printer**  
   Inventory → Print Barcode Labels

2. **Select Products**  
   Check boxes next to products you want

3. **Set Quantity** (Optional)  
   Enter how many labels per product

4. **Preview** (Recommended)  
   Click "Preview (WYSIWYG)" to see exact output

5. **Print or Download**  
   - **Download PDF**: Save file, then open in viewer and Ctrl+P
   - **Print Now**: Direct to printer

## 🖨️ PRINTING STEPS

### Method 1: Download & Print (Recommended)

```
1. Click "Download PDF"
   ↓
2. File saves (barcode-labels-production-YYYY-MM-DD.pdf)
   ↓
3. Open PDF in your PDF reader
   ↓
4. Press Ctrl+P (or Cmd+P on Mac)
   ↓
5. Select your thermal printer
   ↓
6. IMPORTANT: Set scale to 100%
   ↓
7. Turn OFF "Fit to page" / "Shrink to page"
   ↓
8. Click "Print"
```

### Method 2: Print Now (Direct)

```
1. Click "Print Now"
   ↓
2. Browser print dialog opens (pre-configured)
   ↓
3. Verify thermal printer is selected
   ↓
4. Verify scale is 100%
   ↓
5. Click "Print"
```

---

## ⚠️ COMMON MISTAKES (AVOID THESE!)

| ❌ WRONG | ✅ CORRECT |
|---------|-----------|
| Print scale = "Fit to page" | Print scale = **100%** |
| Print scale = "Shrink to fit" | Print scale = **100%** |
| A4 paper size in printer | **50×25mm thermal stickers** |
| Margin settings in printer | Margins = **0mm** |
| Regular inkjet printer | **Thermal printer** |

**The #1 reason labels print wrong: Scale is not set to 100%!**

## 📞 TROUBLESHOOTING

### Q: Labels are too small/large
**A:** Check printer scale in print dialog - must be **100%**

### Q: Logo not showing
**A:** Upload logo in Settings → Print & Barcode, then refresh

### Q: Barcode won't scan
**A:** Verify barcode height is 6-8mm, test with different scanner

### Q: Text is cut off
**A:** Product names over 25 chars get truncated - keep names short

### Q: Blank pages printing
**A:** Every product generates 1 label - not an error

### Q: Wrong printer selected
**A:** Open print dialog, select correct thermal printer before printing

## 💡 PROFESSIONAL TIPS

1. **Always preview first** - 2 seconds saves wasted labels

2. **Test print first** - Print 1-5 samples on real stickers before bulk

3. **Keep product names short** - Max 25 characters for best appearance

4. **Upload professional logo** - Better branding, increases perceived value

5. **Batch print** - Print multiple products at once (10+ together)

6. **Store PDFs** - Save generated PDFs for reordering without regenerating

7. **Label stickers matter** - Use quality 50×25mm thermal stickers
