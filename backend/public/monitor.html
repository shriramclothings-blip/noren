All actions below are irreversible or destructive. Each requires explicit confirmation. Use with extreme caution in production.
// Shutdown Info

Graceful shutdown sends process.exit(0) after a 3-second drain window. On Render, the dyno will restart automatically. You can use this to force a clean restart after environment variable changes.

Requires MONITOR_SECRET to be set in your .env file. Without it, shutdown is disabled.

⚡ Confirm DB Switch
You are about to force-switch the active database node. All new queries will route to the new node immediately. Current in-flight queries will complete on the old node.
📋 Confirm Database Copy
This will TRUNCATE all tables on the destination node and copy every row from the source. This is irreversible. Estimated time: 1–10 minutes depending on data size.
🔴 Graceful Server Shutdown
Enter your MONITOR_SECRET and a reason. The server will drain for 3 seconds then exit. On Render, it will auto-restart.
🚫 Block All Login Services
This will IMMEDIATELY block all authentication across:
• Main Website (norenfastion.shop)
• Seller Portal (sell.norenfastion.shop)
• Support Portal (support.norenfastion.shop)

Users attempting to login will see "Login service temporarily blocked".
✅ Resume Login Services
This will immediately resume all authentication services across all portals. Users will be able to login normally.
